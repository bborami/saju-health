# 사주와 건강

사주(일주) 기반 건강 조언 웹사이트입니다. 생년월일시를 입력하면 만세력을 보여주고,
일주 캐릭터와 함께 일주의 특징과 건강의 좋은 점, 신경 쓸 점을 재미있게 안내합니다.

> 재미용 콘텐츠이며 의학적 진단이나 치료를 대신하지 않습니다.

## 진행 계획

1. 일주 콘텐츠: 60갑자 일주별 캐릭터, 오행 테마, 특징, 건강 좋은 점/주의할 점
2. 만세력 계산: 양력/음력 입력, 절기 기준 년·월·일·시주 계산
3. 웹사이트 화면: 일주 캐릭터 등장 + 스크롤 따라다니기, 오행 배경, 모바일 우선
4. 미리보기 공개와 심의용 문구 정리

## 현재 상태
